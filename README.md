# BusinessCard

A digital business card for Sean Nedorez — Senior SAP Human Resources Consultant with a Computer Science background. Built with plain HTML & CSS only.

Exersice number 1 for course - Internet Applications

## Features

- Profile header with photo, title, location, and contact links (GitHub, LinkedIn, email, phone)
- About section
- Projects showcase
- Skills list
- Light/dark theme toggle (pure CSS, no JS)
- Responsive layout
