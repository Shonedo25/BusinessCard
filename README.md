# BusinessCard

A digital business card for Sean Nedorez — Senior SAP Human Resources Consultant with a Computer Science background. Built with plain HTML & CSS only, no JavaScript (a checkbox-driven toggle powers the light/dark theme switch).

## Features

- Profile header with photo, title, location, and contact links (GitHub, LinkedIn, email, phone)
- About section
- Projects showcase (Eureka, Mingo, Yeshiva.ai, Investments_sum)
- Skills list
- Light/dark theme toggle (pure CSS, no JS)
- Responsive layout

## Structure

- [index.html](index.html) — page markup and content
- [style.css](style.css) — styling and theme
- [assets/](assets/) — images (profile photo)

## Usage

Open [index.html](index.html) directly in a browser, or serve the folder with any static file server.
